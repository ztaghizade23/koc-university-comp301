# Koc University Comp301
Here, I share my personal resources for the Koç University class COMP301: Programming Language Concepts from Spring25.

I have gotten A+ from this course; However, note that it is *very* likely that there are mistakes in the notes and ps solutions.

My take on the course: This course is about hypothetical programming languages that extend on each other. It introduces students to hands on functional programming (i.e. scheme/drracket) and theoretical elements of programming languages. It primarily tests how comfortable students are with recursive and algorithmic thinking, as well as quickly grasping new programming languages. If you think you are already good at these, then this course will be a piece of cake. Otherwise, it will be very challenging. Enjoy.

One advice: there is a set of homeworks by the name "Project 1". Take it seriously, even if you use AI for everything else, do this one independently if you wanna do well in the course. If this set of homeworks comes easy for you, there's a high chance you will get an A/A+.
